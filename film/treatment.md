# 五种控件，怎样向 AI 描述

20 秒，1920×1080，60 fps；沿用最初的钴蓝与柠檬黄、左侧大标题和右侧操作画面。无旁白，使用短字幕、配乐和音效。

## 知识目标
观众能为五种控件选择合适场景，并学会“场景 + 动作 + 反馈”的提示词写法。所有画面提示词都是可复用的简短起点，源码 README 提供可复制版本。示例数据和提交状态均为模拟。

## 分镜
| 时间 | 控件 / 场景 | AI 提示词 | 操作 |
|---|---|---|---|
| 0–2 | 五种控件总览 | 别只说“高级 UI” | 展示五种并标号 |
| 2–5 | 双端滑块 / 电商价格筛选 | 做价格双端滑块，数值跟随拖动，两端不可交叉。 | 拖动上下限 |
| 5–8 | 日期选择 / 酒店入住离店 | 做酒店日期区间选择，支持修改，点击确认才生效。 | 选择区间并确认 |
| 8–11 | 验证码 / 手机号登录 | 做六格登录验证码，自动跳格，填满后显示校验结果。 | 自动跳格与确认反馈 |
| 11–14 | 上传 / 提交资料 | 做资料拖拽上传，显示进度，完成后给出反馈。 | 文件拖入、进度、完成 |
| 14–17 | 目录 / 项目文件 | 做项目文件树，可展开，选中高亮并显示路径。 | 展开、选中文件 |
| 17–20 | 提示词公式 | 场景 + 动作 + 反馈 | 五控件总览，公式收束 |

120 BPM，40 拍，10 小节，首拍 0 秒。切点位于整数拍；主和弦在 18 秒落地，最后两秒保留衰减尾音。每段提示词从进入场景就完整显示，避免打字动画占用阅读时间。

## 参考核实
交互能力参考 BoardUI 的公开组件说明，独立绘制，无原站源码。业务场景为本片举例。

- 双端滑块：双端区间、数值展示、手柄不交叉。https://www.boardui.com/zh-hans/components/slider
- 日期选择：日期区间与提交。https://www.boardui.com/zh-hans/components/date-picker
- 验证码：分格输入和自动推进。https://www.boardui.com/zh-hans/components/input-otp
- 上传：拖放与进度反馈。https://www.boardui.com/zh-hans/components/file-upload
- 文件树：展开和选择层级。https://www.boardui.com/zh-hans/components/tree-view
