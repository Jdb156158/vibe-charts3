## 网页可以怎么玩

| 控件 | 适用场景 | 网页操作 |
|---|---|---|
| 双端滑块 | 电商价格筛选 | 拖动上下限，数值同步，两端不能交叉 |
| 日期选择 | 酒店入住 / 离店 | 选择开始和结束日期，点击应用才提交 |
| 六格验证码 | 手机号登录 | 自动跳格，支持粘贴六位；输入 482619 看成功反馈 |
| 拖拽上传 | 提交资料 / 导入文件 | 拖放或选择文件，体验进度与完成状态 |
| 树形目录 | 项目文件 / 知识库 | 展开 src、components，选择文件查看完整路径 |

网页对照影片还原五个控件的布局、数据和操作，支持桌面、手机和键盘。上传与验证码为本地模拟，文件不会发送到服务器。

## 五条 AI 提示词

1. **双端滑块：** 做价格双端滑块，数值跟随拖动，两端不可交叉。
2. **日期选择：** 做酒店日期区间选择，支持修改，点击确认才生效。
3. **验证码：** 做六格登录验证码，自动跳格，填满后反馈校验结果。
4. **文件上传：** 做资料拖拽上传，显示进度，完成后给出反馈。
5. **树形目录：** 做项目文件树，可展开，选中高亮并显示路径。

这些是描述交互的起点，可以继续添加品牌、技术栈与业务边界。[完整提示词与影片制作提示词](docs/PROMPTS.md)。

## 制作步骤

1. 阅读 BoardUI 五种组件的说明，核对交互能力，选取业务场景。
2. 编排 20 秒时间线：2 秒钩子、五段各 3 秒、3 秒总结。
3. 用 Canvas 编写 `window.draw(t)`，本地加载字体；每个画面只由时间决定。
4. 先输出九帧检查排版与可读性，第二轮放大提示词至 38px。
5. Python 合成 120 BPM 音乐和操作音，完整 10 小节，结尾淡出。
6. Playwright 生成 1200 帧 JPG；FFmpeg 合成兼容浏览器的 H.264 + AAC MP4，启用 faststart。
7. 原生 HTML/CSS/JavaScript 实现可交互网页，检查五类操作、手机排版和视频播放。
8. GitHub Pages 从 main 分支根目录发布。

[详细复现步骤](docs/MAKING.md) · [分镜与来源](film/treatment.md) · [许可与参考](docs/CREDITS.md)

## 本地运行

无需构建步骤，在仓库根目录运行：

```sh
python3 -m http.server 8000
```

然后打开 http://localhost:8000/。视频渲染入口在 `film/`，使用方法见 [film/README.md](film/README.md)。

## 文件结构

- `index.html`、`site/`：交互网页。

- `film/`：Canvas 动画、字体、音乐、渲染脚本与分镜。
